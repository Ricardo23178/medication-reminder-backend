依据目录中的毕业设计方案、任务书和开题报告，对已实现的 HarmonyOS 客户端与 Spring Boot 后端进行优化。当前范围为登录、药品关联、用药计划、提醒确认、服药记录、家属绑定和异常查询、日历统计；不新增后续模块，不续写论文或开题报告。

## 文档要求与本次修改

| 文档要求 | 已发现问题 | 本次处理 |
| --- | --- | --- |
| 计划暂停、变更、取消后待执行任务失效 | 只修改计划，提醒仍可确认 | 事务内取消 WAITING/TRIGGERED；恢复仅处理当前规则、未来时刻、有效日期内的提醒 |
| 数据归属校验 | 修改计划可引用他人药品 | 修改时按药品 ID + 当前用户校验；非法关联在写入前拒绝 |
| 时间与边界校验 | 日期倒置、重复或非法时间点可进入服务 | 校验起止日期、HH:mm、重复时间、提醒数量和正剂量 |
| 幂等和状态一致性 | 确认、超时扫描可能覆盖状态；异常通知无业务ID | 条件更新竞争状态；同一事务写记录、异常、通知；通知绑定异常ID |
| 已服、稍后、跳过含义明确 | 稍后被直接标为最终确认 | 稍后保持待确认并延长确认窗口；最终确认更新原记录，超时形成UNCONFIRMED记录 |
| 跨日时间处理 | 午夜后确认归错统计日；延后的任务跨日后不可见 | 按原定提醒日期统计；当日列表包含仍在确认窗口内的前一天待确认任务 |
| 家属最小授权与邀请码防重放 | 异常查询未检查scope；并发可领取同一码 | 检查ABNORMAL_EVENT授权；限制授权枚举；条件更新领取邀请码并显式清空 |
| 接口保护与敏感日志 | 普通用户可触发全库任务；日志输出默认口令 | 辅助接口仅ADMIN可调用；去掉口令日志；默认关闭SQL明细日志 |
| 弱网、重复点击、Token过期 | 连续提交、过期后仍停留在业务页 | 提交防重入；401清理会话并返回登录页，保留新登录会话的凭证 |
| 统计准确与屏幕适配 | 稍后被算作完成；取消任务计入分母；进度条固定宽度 | 完成率为已服/应完成；取消任务排除；进度条使用0～100%的容器宽度 |
| 配置可维护 | 连接与密钥只能直接改源码 | 支持数据库、JWT和SQL日志环境变量覆盖，保留本地配置兼容性 |
| 本地登录联调 | 前端使用已失效的电脑IP，后端正常仍提示网络失败 | 模拟器使用127.0.0.1与HDC反向端口转发；更新启动说明，避免Wi-Fi地址变化影响调试 |
